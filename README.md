# StudyTracker (ASP.NET Core MVC)
Веб-приложение для управления учебным процессом, позволяющее преподавателям создавать курсы, назначать задания и отслеживать успеваемость студентов.

## Технологический стек
*   **Язык:** C#
*   **Платформа:** .NET, ASP.NET Core MVC
*   **Frontend:** Razor Views, HTML, CSS
*   **Аутентификация:** ASP.NET Core Identity / JWT
*   **Контейнеризация:** Docker
*   **Архитектура:** MVC

## Основной функционал
*   **Авторизация и роли:** Разделение доступа (AuthController).
*   **Управление курсами:** Создание, редактирование и просмотр курсов, назначение студентов на курс.
*   **Управление задачами:** Создание и назначение заданий (TaskController).
*   **Отчетность:** Генерация отчетов по успеваемости (ReportController).

## Как запустить локально
**Способ 1: Через Visual Studio**
1. Клонируйте репозиторий.
2. Откройте `.sln` файл в Visual Studio.
3. Настройте строку подключения к БД в `appsettings.json`.
4. Запустите проект.
